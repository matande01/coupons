# Cop · קופ — הקופונים שלי

**כתובת האפליקציה:** https://matande01.github.io/coupons/

אפליקציית ווב (PWA) לניהול קופונים, גיפט קארדים ושוברים: מוסיפים אותה למסך הבית באייפון והיא מתנהגת כמו אפליקציה רגילה.
כל המידע נשמר **רק על המכשיר** (IndexedDB), ושום דבר לא נשלח לשרת.

## טכנולוגיות

| חלק | בחירה | למה |
|---|---|---|
| ממשק | React 19 + Vite | מהיר, פשוט, מתאים לאפליקציה בצד הלקוח בלבד |
| עיצוב | Tailwind CSS 4 | RTL מובנה (`ms-`/`me-`/`start`/`end`), מותאם למובייל |
| אחסון | IndexedDB דרך Dexie | שומר גם תמונות, עדכון אוטומטי של המסך |
| זיהוי טקסט | Tesseract.js (עברית + אנגלית) | רץ על המכשיר, חינם, עובד גם בלי אינטרנט אחרי הפעם הראשונה |
| ברקוד / QR | ZXing | מחזיר את הקוד המדויק כשיש ברקוד בתמונה |
| אפליקציה במסך הבית | vite-plugin-pwa | אייקון, מסך מלא, עבודה בלי אינטרנט |

## הרצה על המק (M1 ומעלה)

צריך Node.js 20 ומעלה (מותקן אצלך: v26).

```bash
cd "/Users/user/Desktop/claude proj/coupons"
npm install        # רק בפעם הראשונה
npm run dev
```

ואז פותחים בדפדפן את http://localhost:5173

## ניסיון על האייפון באותה רשת Wi-Fi

כש-`npm run dev` רץ, הוא מציג כתובת `Network`, למשל `http://192.168.10.174:5173`. פותחים אותה בספארי באייפון.
זה טוב לבדיקה בלבד: המק צריך להיות דלוק, וכתובת ה-IP יכולה להשתנות (ואז הנתונים לא יופיעו, כי הם שמורים לפי כתובת).

## התקנה קבועה על האייפון

האפליקציה מפורסמת ב-GitHub Pages: https://matande01.github.io/coupons/

אחרי שינוי בקוד, מפרסמים גרסה חדשה כך:

```bash
npm run deploy     # בונה ומעלה לענף gh-pages; האתר מתעדכן תוך דקה-שתיים
```

האפליקציה בטלפון מתעדכנת לבד בפתיחה הבאה, והקופונים נשארים.

ואז באייפון: ספארי ← הכתובת ← כפתור השיתוף ← **"הוסף למסך הבית"**.

הערות חשובות:
- הקופונים עדיין נשמרים **רק בטלפון**. האחסון משמש רק להגשת הקוד, והנתונים לא עולים אליו.
- אפליקציה שנפתחת ממסך הבית שומרת נתונים בנפרד מהאתר בספארי. לכן מוסיפים קופונים **מתוך האייקון במסך הבית**.
- בסריקה הראשונה צריך אינטרנט: מורידים פעם אחת את מנוע הזיהוי וקבצי השפה (כ-10MB). אחר כך הכל עובד בלי חיבור.
- כדאי לשמור **גיבוי** מדי פעם (תפריט ⋮ ← שמירת גיבוי ← שמירה ב-iCloud Drive).

## איך עובד הזיהוי מתמונה

1. **ברקוד/QR** (ZXing): אם נמצא ברקוד שאינו קישור, הוא משמש כקוד הקופון.
2. **OCR** (Tesseract, עברית + אנגלית) על גרסה מוגדלת בשחור-לבן עם ניגודיות משופרת.
3. **ניתוח הטקסט** (`parse.js`), שורה אחר שורה:
   - **סכום**: מספר ליד ₪ או ש"ח, או בשורה עם "סכום/שווי/יתרה/בסך". מספרים שהם תאריכים או טלפונים לא נחשבים.
   - **תוקף**: תאריך (dd/mm/yyyy, dd.mm.yy, yyyy-mm-dd) בשורה עם "תוקף/עד/valid/exp". אם יש כמה תאריכים, נבחר המאוחר.
   - **קוד**: רצף ספרות ואותיות ליד "קוד/מספר שובר/כרטיס/code". מספרי טלפון מקבלים ציון נמוך.
   - **PIN**: מספר קצר ליד "קוד סודי/PIN/CVV".
   - **מותג**: לפי הרשימה ב-`brands.js`, כולל כתיב בעברית ובאנגלית ותחיליות כמו "בקרפור".

שדות שזוהו מסומנים ב"✦ זוהה", וצריך לבדוק אותם לפני השמירה. אם מותג לא מזוהה, מוסיפים אותו ל-`src/lib/brands.js`.

## תפיסת שובר ממייל (Voucher Catcher)

מעתיקים מייל עם גיפט קארד, ובאפליקציה לוחצים **＋ ← תפיסת שובר ממייל ← הדבקה מהמייל ותפיסה**. קופ מזהה את המותג, הקוד, ה-PIN, הסכום והתוקף:
- **כל הפרטים נמצאו** (מותג, קוד וסכום): השובר נשמר מיד, בדיוק כמו קופון שהוזן ידנית.
- **חסר משהו:** נפתח טופס "קופון חדש" עם מה שנמצא, ואתם משלימים ושומרים.
- **השובר כבר שמור** (אותו קוד): לא נשמר שוב.

הכל קורה בטלפון, בלי שרת. הטקסט לא יוצא מהמכשיר.

### קיצור דרך באייפון (חינם, בלי תחזוקה)
אפליקציית מסך הבית לא יכולה לקבל נתונים ישירות מ"קיצורים", ולכן הקיצור מעתיק את המייל ומזכיר לכם לפתוח את קופ:

1. קיצורים ← **אוטומציה** ← **＋** ← **דואר** (Email).
2. **השולח הוא:** כתובות המייל של הספקים (קרפור, Terminal X וכו'). אפשר במקום זה לבחור **הנושא מכיל** "גיפט קארד" או "שובר".
3. לבחור **הפעלה מיידית** ← הבא ← **אוטומציה ריקה** חדשה.
4. להוסיף את הפעולה **העתקה ללוח** (Copy to Clipboard) עם **קלט קיצור** (Shortcut Input).
5. להוסיף את הפעולה **הצגת התראה**: "קופ תפס שובר! פתחו את Cop ← ＋ ← תפיסת שובר ממייל".

אם הקיצור מעתיק רק את נושא המייל, מוסיפים לפני ההעתקה את הפעולה **קבלת טקסט מקלט** (Get Text from Input).
גם בלי קיצור אפשר פשוט לסמן את המייל, להעתיק אותו ולהדביק בקופ.

### הוספת ספק חדש
כל ספק הוא קובץ קטן בתיקייה `src/lib/providers/`:
1. מעתיקים את `carrefour.js` לקובץ חדש ומשנים את `brand`, את `detect` (איך מזהים את המייל) ואת הביטויים של כל שדה. הקבוצה הראשונה בסוגריים היא הערך.
2. מוסיפים אותו לרשימה `PROVIDERS` ב-`src/lib/providers/index.js`, ואת שם המותג ל-`src/lib/brands.js`.
3. מוסיפים דוגמת מייל ל-`scripts/test-catch.mjs` ומריצים `npx vite-node scripts/test-catch.mjs`.

שדה שספק לא מגדיר, או שהביטוי שלו לא מצא, נלקח מהזיהוי הכללי, כך שגם מותגים בלי קובץ ייעודי עובדים לרוב.

## עדכון יתרה

`recordSpend` ב-`src/lib/coupons.js`:
- החישוב נעשה באגורות (מספרים שלמים), כדי שלא ייווצרו שגיאות עיגול כמו ‎0.1+0.2.
- הקופון נקרא מחדש **בתוך טרנזקציה** לפני העדכון, כך שלחיצה כפולה לא תוריד פעמיים מיתרה ישנה.
- אי אפשר להוריד יותר מהיתרה או סכום אפסי.
- כל שימוש נשמר בהיסטוריה, ואפשר לבטל את האחרון (מההודעה הקופצת או ממסך הפרטים).
- כשהיתרה מגיעה ל-0, או כשהתוקף עובר, הקופון עובר אוטומטית לארכיון.
